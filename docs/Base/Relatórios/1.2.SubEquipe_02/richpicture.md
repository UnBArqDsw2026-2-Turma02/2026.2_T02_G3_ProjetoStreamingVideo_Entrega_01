# Rich Picture

As Rich Pictures são mapas visuais que combinam imagens, textos, símbolos e ícones para ilustrar os elementos de uma situação e como eles se conectam. Elas servem para facilitar a compreensão do contexto geral e revelar oportunidades de melhoria. Na Streaming de Vídeo, esse recurso é usado para desenhar a plataforma, destacando suas funcionalidades principais e a forma como os usuários interagem com o sistema.

## Legenda

Conforme aponta Revadi (2018, p. 4), a estruturação das Rich Pictures baseia-se em cinco pilares centrais: atores, operações, fluxo ou armazenamento de dados, setas e delimitadores do sistema.
