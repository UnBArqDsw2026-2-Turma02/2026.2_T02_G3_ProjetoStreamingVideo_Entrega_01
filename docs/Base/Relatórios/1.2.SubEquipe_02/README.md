Este diretório reúne o relatório e os artefatos produzidos pela **SubEquipe 02** para o primeira entrega de **Arquitetura e Desenho de Software**.

A entrega foi organizada de acordo com os três focos definidos para a disciplina:

1. **Artefatos Generalistas & NFR Framework**
2. **Engenharia Reversa & Modelagem BPMN**
3. **IA Generativa**

Os artefatos específicos foram mantidos em páginas separadas para facilitar a navegação, a manutenção da documentação e a consulta durante a apresentação.

## Organização da Documentação

A estrutura foi dividida entre o **relatório principal** e os **artefatos específicos** para evitar concentração excessiva de conteúdo em uma única página e permitir que cada artefato apresente seu contexto, metodologia e resultados com maior clareza.

O relatório principal funciona como ponto de integração da entrega, enquanto as páginas individuais apresentam em maior detalhe os materiais produzidos em cada foco.
