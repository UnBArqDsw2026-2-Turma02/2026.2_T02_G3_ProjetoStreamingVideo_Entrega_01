# Engenharia Reversa

Este arquivo será usado para registrar a análise, os passos da engenharia reversa e o fluxo do sistema identificado pela equipe.

## Objetivo

Compreender o funcionamento do software e mapear o comportamento principal da aplicação para apoiar a modelagem e a documentação do projeto.

## Conteúdo esperado

- contexto da análise
- ferramentas utilizadas
- passos da engenharia reversa
- principais observações do sistema
- fluxo identificado

## Observações

Este documento pode ser complementado com os demais artefatos da equipe conforme o desenvolvimento do relatório.
